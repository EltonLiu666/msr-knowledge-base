Data Sources

Explore common data sources used in Mining Software Repositories research.

Source Name Data Provided Description
GitHub Repositories, commits, pull requests, issues, stars A code hosting platform that provides information about software development activities and collaboration.
Stack Overflow Questions, answers, tags, user reputation A developer Q&A platform containing technical discussions and programming knowledge.
JIRA Issue tracking, sprint data, bug reports A project management tool used to track software issues, bugs, and development tasks.
App Stores Reviews, ratings, downloads Google Play and Apple App Store provide application feedback and usage-related information.
Travis CI / Jenkins Build logs, test results, deployment data Continuous integration tools that provide information about software builds, testing, and deployment activities.
Mailing Lists Developer discussions, archives Archived communication channels containing discussions about software projects, decisions, and development activities.
npm Registry Package dependencies, downloads, versions A package registry for JavaScript projects that provides information about packages, dependencies, and releases.
